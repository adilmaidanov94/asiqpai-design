# ASIQPAI — UX/UI дизайн-пакет (Telegram Mini App)

## Что это

Пакет поставки по техническому заданию Astana Hub «Разработка UX/UI-дизайна Telegram Mini App ASIQPAI» (утверждено 07.10.2026, ответственное лицо заказчика — Колмаков Евгений Олегович). ASIQPAI — музыкальная AI-платформа для независимых артистов Казахстана: рэперов, вокалистов, битмейкеров и начинающих музыкантов. Интерфейс локализован на русский, казахский и английский.

Пакет сделан по принципу code-first: дизайн-система, экраны и прототип описаны в HTML/CSS/JS на единых токенах. Это даёт разработчикам точные значения без ручного переноса из макетов, а прототип открывается на любом телефоне по ссылке. Все документы — на русском языке.

## Как открыть

1. Документы и UI Kit открываются двойным щелчком по `design/index.html`.
2. Для прототипа нужен локальный сервер: шрифты и библиотека диаграмм подгружаются с CDN, а экраны и данные — относительными путями, которые браузер блокирует при открытии с диска.

```bash
cd ASIQPAI
python3 -m http.server 8765 --directory design
```

Затем откройте в браузере `http://localhost:8765/prototype.html`. На компьютере прототип показывается в рамке 390×844; боковая панель переключает сценарии, экраны и состояния (крупный текст, нет сети, пустая библиотека, длинные строки KZ).

3. На телефоне: подключите его к той же Wi-Fi-сети и откройте `http://<IP-компьютера>:8765/prototype.html` — прототип развернётся на весь экран, как Mini App в Telegram.

## Про Figma

Система поставляется в коде как в источнике истины. Чтобы получить редактируемые фреймы в Figma:

- установите плагин **html.to.design** и импортируйте нужные экраны прототипа или страницу `uikit.html` (каждый экран становится фреймом с автолейаутом), либо используйте «Figma → Import HTML», если он доступен в вашем воркспейсе;
- импортируйте `design/assets/tokens.json` через плагин **Tokens Studio** — он создаст Figma Variables для цветов, типографики, радиусов и отступов, совпадающие с `tokens.css`.

После предоставления заказчиком Figma-воркспейса мы выполним импорт и сверку сами в рамках Этапа 6.

## Статус и следующие шаги

| Этап | Содержание | Статус v1.0 |
|---|---|---|
| 1 | Старт и UX-аудит | Выполнен на основе ТЗ и публичных материалов |
| 2 | IA и user flow | Выполнен |
| 3 | Визуальная концепция и Design System | Выполнен, палитра и шрифты предложены как рабочая версия |
| 4 | Дизайн ключевых экранов | Выполнен, включая состояния loading / empty / error / success / disabled / confirmation |
| 5 | Прототип и пользовательская проверка | Прототип готов; план и протокол теста — в `docs/04-usability-test.html`, сессии проводятся после согласования участников |
| 6 | Финализация и Handoff | Черновик handoff готов; финализация после результатов теста |

Что требуется от заказчика:

- доступ к текущему MVP для уточнения аудита и реальных сценариев;
- бренд-материалы (логотип в исходнике, фирменные цвета, если они утверждены);
- утверждение финальной палитры и шрифтов;
- Figma-воркспейс для импорта макетов и токенов;
- помощь с рекрутингом участников юзабилити-теста из сообщества.
